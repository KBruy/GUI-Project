# Tłumaczenia (i18n)

Jak dodawać i używać tłumaczeń w komponentach. Obsługiwane języki: `pl` (domyślny), `en`.

---

## Jak dodać nowy klucz

Otwórz `src/i18n/dictionary.ts` i dopisz parę klucz → `{ pl, en }`:

```ts
const dictionary = {
  // ... istniejące klucze
  'moj.nowy.klucz': { pl: 'Mój tekst po polsku', en: 'My text in English' },
} satisfies Record<string, { pl: string; en: string }>
```

TypeScript od razu udostępni nowy klucz w `t()`. Literówka w kluczu to błąd kompilatora — nie runtime.

---

## Jak użyć tłumaczenia w komponencie

```tsx
import { useT } from '@/i18n/language'

function MyComponent() {
  const { t } = useT()

  return <p>{t('nav.editor')}</p>
}
```

`useT()` zwraca też `language` (aktualny język) i `setLanguage` (zmiana języka):

```tsx
const { t, language, setLanguage } = useT()

<button onClick={() => setLanguage('en')}>
  {language === 'pl' ? 'English' : 'Polski'}
</button>
```

`setLanguage` zapisuje wybór w `localStorage` (`worldsmith.lang`) i aktualizuje atrybut `lang` na `<html>` dla czytników ekranu.

---

## Konwencja kluczy

Klucze są płaskie (string), ale stosujemy notację z kropką dla czytelności:

| Prefiks | Zastosowanie |
|---|---|
| `app.*` | Tytuły, globalne etykiety |
| `nav.*` | Nawigacja |
| `theme.*`, `lang.*` | Ustawienia interfejsu |

Nie ma interpolacji — jeśli tekst wymaga dynamicznej wartości, sklej go po stronie komponentu.

---

## Struktura plików

```
src/i18n/
  dictionary.ts       ← tu edytujesz tłumaczenia
  language.ts         ← LanguageContext, useT(), getInitialLanguage()
  LanguageProvider.tsx ← komponent providera
  useT.test.tsx       ← testy hooka
```
