# Assets

Bazowe sprite’y i komponenty (włosy, ubrania, bloki mapy).

## Grafiki zastępcze

Obecne pliki w `map/` to tymczasowe figury z literą w środku (T trawa, W woda, Kr krzak, D drzewo, K kamień, Ł kłoda). Dzięki nim paleta i edytor działają, zanim powstaną prawdziwe grafiki.

Prawdziwą grafikę wystarczy zapisać pod tą samą nazwą pliku. Jeśli zmienia się jej rozmiar, trzeba poprawić `width` i `height` w `manifest.json`. Nowe grafiki dopisujemy jako nowe wpisy w manifeście.
